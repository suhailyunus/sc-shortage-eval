# ML Concepts 📘

This repository contains notebooks and mini-projects covering essential machine learning concepts.  
Each notebook is focused on hands-on implementation and explanations.

## 📂 Structure

- `Standardization_vs_Normalization.ipynb` – Comparing feature scaling techniques
- `ROC_Curve_Analysis.ipynb` – ROC and AUC explained with code
- More concepts coming soon...

## 🧠 Goal

To build a practical and intuitive understanding of ML fundamentals by implementing them step-by-step.

## 🚀 How to Use

1. Clone this repo.
2. Open the notebooks in Jupyter or Colab.
3. Experiment, tweak, and learn!
